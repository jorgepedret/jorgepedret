## Featured projects

Most of these are client or team work, so the code is private. The live sites are linked.

- **[Celebrator](https://celebrator.app/)**: Web app for photographers and videographers to collect client and contributor uploads and publish showcase pages. Multi-tenant teams, presigned direct-to-storage uploads on Cloudflare R2, row-level security in Supabase, weekly email digests. *Next.js, TypeScript, Supabase, Cloudflare R2, Resend, Vitest.*
- **[StartOver.Earth](https://startover.earth/)**: Renders a Notion workspace as a website, with a members-only experiment-logging game, an admin area, and a Strikingly-to-Notion migration tool. Team project, one of five contributors. *Next.js, Notion API, Supabase, Redis, Docker, Vitest, Playwright.*
- **[Pacific Marine Circle Route](https://pacificmarinecircleroute.ca/)**: Fundraising and event site for a 5-day mental-health run, with a photo and video timeline, sponsor grid, and newsletter signup. *Next.js, Resend, PostHog, Vercel.*
- **[Unhookable](https://unhookable.world/)**: Site for a collective of creators, with members, offerings, events, a store, and a creator signup flow that writes to Supabase and sends email through Resend. Deployed to a VPS with GitHub Actions and pm2. *Next.js, Supabase, Resend, GitHub Actions.*
